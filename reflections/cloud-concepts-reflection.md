I use Google Drive, Messenger, and Word almost every day. These apps help me in school and in communicating with other people. Google Drive is very useful because I can save my files online and open them anytime, even if I am not using my own device. It also helps me keep my school files safe and organized. Messenger is helpful because I can easily talk to my classmates, friends, and family. We use it to share reminders, ask questions, and send updates about school work. Word is also important to me because I use it to make assignments, write reports, and format my work neatly.

These apps are examples of SaaS because I use them directly through the internet. I do not need to install or manage the system myself. Google Drive, Messenger, and Word are also connected to the public cloud because they are available to many users online. I chose these models because they are easy to use, and I can access them anytime as long as I have internet connection.

Git and GitHub are important in cloud projects because they help track changes in a project. If someone makes a mistake, it is easier to go back and fix it. GitHub also helps people work together because team members can share updates and check each other’s work. This makes collaboration easier and helps avoid confusion. Version control is important because it keeps the project organized and prevents losing important work.Overall, cloud applications make my school tasks easier and faster. They help me save files, communicate, and finish my work in a more organized way.
